## Who are you?
Hi there! We are [Sparrow](https://github.com/SP4R0W) and [Varga](https://github.com/VargaDot), a small, two men game development team which specializes in 2D games made in the Godot Engine. Originally, this was meant to be a portfolio only thing, however we quickly decided to treat this more seriously and start developing more new games and fulfilling our dreams in the process.

## Tell me about your work
Our work is [open-source](https://github.com/Sparrowworks), We've made [9 games](https://sparrowworks.itch.io/) so far with [Infamy](https://sparrowworks.itch.io/infamy) being a "real IP" the rest are learning projects more or less.

We also created game systems like the scene manager [Composer](https://github.com/Sparrowworks/ComposerGodot) and our weapon system [Vanguard](https://github.com/Sparrowworks/Vanguard) which you can also find in the [Godot asset library](https://godotengine.org/asset-library/asset?user=SparrowWorks)!

## What tools do you use?
1. [Godot](https://godotengine.org/) - Game engine
2. [Git](https://git-scm.com/) - To keep track of changes to code
3. [Github](https://github.com/) - For hosting code and coordinating work.
4. [GitHub Pages](https://pages.github.com/) - To host this website
5. [GitHub Desktop](https://github.com/apps/desktop) / [SourceTree](https://www.sourcetreeapp.com/) - To upload & download code to & from GitHub and locally
6. [Aseprite](https://www.aseprite.org/) - Pixel art
7. [Audacity](https://www.audacityteam.org/) - Sound stuff
8. Our website - Scroll down :3
