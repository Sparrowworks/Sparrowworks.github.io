## Library Description
Vanguard is a library of simple 2D weapon system catered to hobbyists, begginers and alike. It provides a collection of classes to:
- Build ranged weapons (like guns and bows) using Ranged.
- Create arrows, bullets and all sorts of projectiles using Projectile.
- Create explosion, noise and status-effect inducing (poison, burning...) areas with Field.
- Register, equip and unequip weapon modification using kits.
- Build upon a core Weapon class and create your own custom classes and weapon types.
- Copy and "mass produce" like Melee, Hitbox and Hurtbox.
<br>
The codebase is pretty small and the included documentation covers everything. If you have a question, feel free to create an issue with the "Question" label on our repo page.

## Getting Started
Download the latest release and copy the addons folder to your project. Then, follow these steps (available also in the repo's README):
1. Open the blueprints folder.
2. Open the desired folder of your choice.
3. Right click on the scene.
4. Click on "Inherit New Scene".
5. Enjoy!

Full usage instructions are available on our repo page: [Sparrowworks/Vanguard](https://github.com/Sparrowworks/Vanguard)
